Репозиторий включает в себя разные програмы на js написанные во время обучения.
Программы разделяются по веткам.
В каждой ветке свое описание

0. all_tasks - Задачи по курсу. Все существующие задачи в одной ветке (строки, числа, объекты и тд)
1. profile - программа управления профилем пользователя
2. task-menager - простой менеджер управления задачами
