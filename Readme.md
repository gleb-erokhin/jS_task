task-menager-pro-upgrade - исправленная версия менеджера управления задачами

Проведена работа над ошибками:
- убран массив CompletedTask, вместо этого все данные работают с массивом tasks
- создано сохранение и загрузка массива в localStorage
- для правильного рендеренга вывода в связи с проблемой LiveServer запросы выведены в консоль
- работа с датой и временем выполнения сделана через JSON.parce и JSON.stryngify
- функция удаления работает одинаково для выполненых задач и не выполненых
- запуск и обработка запросов происходит через консоль браузера, так как при работе с файлом js идет постоянная отрисовка и массив дублируется при вызове за счет обновления liveServer

Функции остались прежние:
- работа с несколькими задачами
- возможность посмотреть выполненые задачи отдельно
- возможность удалить все текущие задачи
- добавление / поиск / удаление задач по id

Памятка по запуску в консоли f12:
- console.log('Создать задачу - setTask(id, "title", "descryption")')
- console.log('Выполнить задачу - completeTask(id)')
- console.log('Показать задачи - showTask(arrays)')
- console.log('Показать выполненые задачи - showTask(tasks.filter(t => t.isCompleted), "Задача завершена")')
- console.log('Удалить задачу - deleteTask(id)')
- console.log('Стереть все задачи - clearTasks(arrays)')
